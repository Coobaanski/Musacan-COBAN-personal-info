# Mein Git-Spickzettel

- `git clone` kopiert ein Repository von GitHub auf meinen Laptop.
  Beispiel: `git clone https://github.com/Coobaanski/Musacan-COBAN-personal-info.git`

- `git status` zeigt mir, welche Dateien neu, geändert oder für den nächsten Commit vorgemerkt sind.
  Beispiel: `git status`

- `git add` merkt ausgewählte Änderungen für den nächsten Commit vor.
  Beispiel: `git add index.html notme.avif`

- `git commit` speichert die vorgemerkten Änderungen als neuen Stand auf meinem Laptop.
  Beispiel: `git commit -m "Add personal information page"`

- `git log` zeigt mir die bisherigen Commits. Mit `--oneline` sehe ich einen Commit pro Zeile.
  Beispiel: `git log --oneline`

- `git push` lädt meine lokalen Commits auf GitHub hoch.
  Beispiel: `git push`

- `git pull` holt neue Commits von GitHub und übernimmt sie in meinen lokalen Branch.
  Beispiel: `git pull`
